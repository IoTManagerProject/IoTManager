# Руководство: добавление нового модуля прошивки

> How-to документ. Модульная система описана в [architecture.md](../architecture.md).

## Структура модуля

Каждый модуль лежит в своей папке внутри каталога по типу
(`src/modules/exec`, `src/modules/sensors`, `src/modules/display`, `src/modules/virtual`):

```
src/modules/<тип>/<modname>/
├── modinfo.json   # описание модуля
└── modname.cpp    # реализация (также допускаются вспомогательные файлы)
```

## `modinfo.json` — основные поля

| Поле | Назначение |
|---|---|
| `menu` | Категория меню (где модуль показывается в панели) |
| `name` | Название элемента конфигурации |
| `description` / `about` | Описание и подсказки (показываются в панели) |
| `author`, `version` | Автор и версия |
| `usedLibs` | Библиотеки по платформам — по ним определяется **совместимость** модуля с платформой (несовместимые модули при смене платформы отключаются) |
| `usedFLASH` / `usedRAM` | Размеры по окружениям (заполняются замером) |
| `moduleDefines` | Дефайны для условной компиляции |
| `about.funcInfo[]` | Встроенные функции `ID.функция()` — используются проверкой сценариев |

> Точный состав полей сверяйте с примерами соседних модулей в `src/modules/`
> (например, с небольшим датчиком или кнопкой).

## Подключение модуля к сборке

1. Добавьте модуль в секцию `modules` конфигурации (`myProfile.json`): путь
   `src/modules/<тип>/<modname>` и флаг `active`.
2. Подключение в сборку происходит через `build_src_filter` в секциях
   `[env:*_fromitems]` файла `platformio.ini` — правка ядра не требуется.
3. В панели magicIoTm модуль появится в разделе «💠 Модули» после перезагрузки
   кэша `modinfo` (`GET /api/modules/reload`).

## Проверка размера

После добавления модуля выполните замер размера прошивки, чтобы получить
`usedFLASH`/`usedRAM` по окружениям:

```bash
measure_size/venv/Scripts/python measure_size/measure.py --env <платформа>
```

Результат пишется в `about.size` в `modinfo.json` (КБ по окружениям) и обновляет
кэши `modinfo`/`platforms` панели.

## Чек-лист

- [ ] Модуль лежит в правильном каталоге по типу.
- [ ] `modinfo.json` заполнен, `usedLibs` перечисляет используемые библиотеки по платформам.
- [ ] Модуль компилируется для целевых платформ (`pio run -e <платформа>`).
- [ ] Размеры замерены (`measure.py`), кэш панели обновлён.
- [ ] В сценариях доступны нужные функции (`about.funcInfo[]`).
