# ADR-0002: Каноническое расположение data_svelte проекта

- **Статус**: принято (коммит `ff0ac5c8`, 2026-09-02)
- **Дата**: 2026-09-02
- **Контекст**

  Папка данных прошивки `data_svelte` проекта magicIoTm располагалась внутри
  результата сборки: `iotm/<платформа>/data_svelte`. Это вызывало путаницу:
  пользовательские конфиги жили рядом с артефактами сборки, а сам каталог
  пересоздавался при сборке. При этом чистить старые артефакты по платформам
  было рискованно (можно было удалить данные проекта).

- **Решение**

  Каноническая папка данных проекта — **всегда в корне проекта**:
  `<проект>/data_svelte`. Изменены:
  - `PrepareProject.py` — `DATA_DIR` указывает на корневую `data_svelte`;
  - `app.py` — `data_dir` для сборки и `get_fs_usage`;
  - `measure.py` — `fs_used_dir`.
  После успешной сборки в `iotm/` остаётся только одна папка с прошивками
  (текущей платформы) — `build.py::_prune_iotm`, остальные удаляются.
  Убран лишний шаг копирования `data_svelte`.

- **Следствия**

  - Плюсы: данные проекта отделены от артефактов; очистка `iotm/` безопасна;
    путь данных одинаков для любого проекта.
  - Минусы: старые проекты, созданные до изменения, нужно переносить
    (`data_svelte` из `iotm/<платформа>/...` в корень проекта).
  - Справочник структуры: [`docs/reference/data-formats.md`](../reference/data-formats.md).
