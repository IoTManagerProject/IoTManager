# Справочник форматов данных

> **Reference**. Структура панели — [architecture.md](../architecture.md).

## Данные прошивки (`data_svelte/`)

Каталог данных файловой системы LittleFS. Содержит веб-интерфейс устройства
и JSON-конфигурации.

| Файл | Назначение |
|---|---|
| `config.json` | Базовая конфигурация элементов (в примере — пустой массив) |
| `items.json` | Список элементов конфигурации с заголовками секций (`executive_devices`, `screens`, `sensors`, `virtual_elments`); каждый элемент описывает тип, подтип, виджет, страницу, описание, пин, параметры |
| `settings.json` | Настройки устройства: имя, группа WG, точка доступа (SSID/пароль), параметры роутера, MQTT (сервер/порт/префикс/пользователь/пароль), NTP, I²C (частоты, пины), таймзона, web-логин/пароль, настройки Wi-Fi-репитера |
| `layout.json` | Раскладка виджетов на веб-странице |
| `values.json` | Значения элементов |
| `ota.json` | Настройки/состояние OTA-обновления |
| `flashProfile.json` | Профиль flash (параметры записи) |
| `index.html`, `favicon.ico`, `edit.htm.gz`, `build/` | Веб-интерфейс устройства и его ресурсы |

## Профиль пользователя (`myProfile.json`, корень репозитория)

Персональная эталонная конфигурация:

- секция `iotmSettings` — те же параметры, что в `settings.json`;
- секция `modules` — список активных модулей с путями (`src/modules/...`) и флагом `active`.

Является шаблоном для создания проектов в magicIoTm; правится напрямую защищённым проектом PlatformIO.

## Проекты панели (`tools/magicIoTm/projects/`)

Структура `projects/[категория]/[проект]/`:

| Файл/папка | Назначение |
|---|---|
| `myProfile.json` | Полная конфигурация (копия из корня при создании проекта) |
| `data.json` | Метаданные проекта |
| `about.txt` | Описание проекта |
| `data_svelte/` | **Каноническая папка данных прошивки проекта** (LittleFS), всегда в корне проекта; заполняется `PrepareProject.py` из `data_full/`/`data_lite/` с сохранением пользовательских конфигов (`settings.json`, `items.json`, `flashProfile.json` и др.) |
| `iotm/<платформа>/400/` | Собранная прошивка (firmware/littlefs/partitions `.bin`); после успешной сборки в `iotm/` — только одна папка текущей платформы |
| `platformio.ini` | PlatformIO-конфиг (для обычных проектов) |

## Папки устройств (`tools/magicIoTm/devices/`)

```
<имя> <id>/              # разделитель — ПРОБЕЛ; если id пуст — <имя> <ip>/
├── .device.json         # метаданные (ip, name, id, wg)
├── RAM/                 # скачанные по WS файлы конфигурации
└── FS/                  # скачанная по HTTP файловая система устройства
```

Легаси-папки с разделителем `_` продолжают распознаваться без создания дублей.

## Сборка (PlatformIO)

`platformio.ini` задаёт окружения, библиотеки (`ArduinoJson @6.18.0`,
`PubSubClient` и др.), флаги сборки, скрипты предобработки, а также
`filesystem = littlefs`, `data_dir = data_svelte`.
